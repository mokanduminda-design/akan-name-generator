# Akan Name Generator📅✨
---
## About the Project
A simple and interactive **Akan Name Generator** built with **HTML, CSS, and JavaScript**.

This application calculates the **day of the week** a user was born and assigns them an **Akan name** based on their **gender** and the day of the week they were born, following Ghanaian cultural naming traditions.

---

## Features
📅 User inputs birth **day, month, and year**  
🚻 Gender selection (Male / Female)  
🧮 Automatic day-of-week calculation  
✅ Correct Akan name assignment  
⚠️ Alerts for invalid or missing input  
⚡ User-friendly and runs in any modern browser

## How to Use
1. Enter your **birth day**, **month**, and **year** in the input fields.

2. Select your **gender**:
   - 👨 Male
   - 👩 Female

3. Click the **Generate Name** button.

The application will automatically calculate the **day of the week** you were born.

Your result will be displayed instantly:

🗓️ Day of the week you were born  
 Your Akan name based on your gender  

⚠️ If any field is empty or an invalid date/month is entered, an alert message will appear.
